### 1. 비트 차트 완성 (Phase 3 마무리)
- [I2C_BitChart_Template.xlsx](./I2C_BitChart_Template.xlsx) — Byte Write / Random Read / Current Address Read 3종 전부 값 채워서 확인 완료

- Random Read: Repeated START 앞뒤로 컨트롤바이트(Write→Read) 방향 전환, 마지막 데이터는 마스터가 NACK
- Current Address Read: 주소 세팅 단계 전체 생략, START 직후 바로 Read 컨트롤바이트

### 2. FSM 3계층 설계 (Phase 4)
`참고사항/BItTxRx_FSM.drawio`, `ByteData_FSM.drawio`, `I2CMaster_FSM.drawio`에 각각 상태 다이어그램 + 상태 전이표(현재상태/입력조건/다음상태/출력) 작성 및 반복 리뷰:

- **BitTxRx (비트 레벨)**: `SCL_LOW→SDA_SETUP→SCL_HIGH` 카운터 기반 3상태. F(대기) 루프 누락, 라벨 오타, 중복 화살표 등 수정
- **ByteData_FSM (바이트 레벨)**: `WAIT→LOAD→SHIFT_BIT→ACK_CHECK→DONE`. 8비트 카운터 off-by-one 버그, `BitStart`/`DriveEn`가 매 클럭 계속 나가던 문제(펄스로 수정) 등 여러 라운드 수정
- **I2CMaster (커맨드 레벨)**: `IDLE→START→CTRL_BYTE→ADDR_H→ADDR_L→(Write:DATA / Read:REP_START→CTRL_BYTE_R→READ_DATA)→STOP`. STOP이 막다른 길이던 문제, Current Address Read가 컨트롤바이트(Write)를 먼저 보내던 프로토콜 위반 수정
- 슬레이브 NACK 예외 처리(6곳 → STOP, `nack_err=1`) 추가

### 3. 아키텍처 정리
- **`I2cMaster`는 SCL/SDA를 직접 만들면 안 된다** — 물리 핀은 `BitTxRx`만 소유. 대신 `I2cStart`/`I2cStop` 요청 신호로 통신하기로 결정
- 신호명 표기 통일: `SdaOe`/`DriveEn`/`BitDone`/`SdaLatch`/`ByteDone`/`BitStart`/`ByteStart` 등 파스칼케이스로 3개 FSM 전부 맞춤

### 4. 남은 최종 점검에서 발견한 것들 (진행 중)
전체 재검토 끝에 정리된 최종 punch list:
- [ ] `BitTxRx`: `WAIT`(트리거 대기) + `GEN_START`/`GEN_STOP` 상태 추가 — **지금 작업 중**

- [ ] `I2cMaster`: `REP_START`에 `I2cStart=1` 누락, `CTRL_BYTE`/`ADDR_H`/`ADDR_L`/`DATA`/`CTRL_BYTE_R`에 실제 보낼 바이트 값(`WriteData=...`) 출력 누락
